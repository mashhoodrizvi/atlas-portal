HOW TO USE:
1. Add/edit records in Google Sheets.
2. Open the website and click Admin login.
3. Enter the same ADMIN_PASSWORD you set in Apps Script.
4. Pending rows will show an Approve button.
5. Click Approve to update the Google Sheet.

GOOGLE SHEET HEADINGS MUST BE:
Date
Actual Time
Invoice Time
Extra Time/Difference
Amount
Status

IMPORTANT:
Do not put the password inside script.js.
The website asks for it and stores it only for the current browser session.
