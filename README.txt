ATLAS QUOTATION BUILDER

Upload these files to the ROOT of your GitHub repository:

- index.html
- style.css
- script.js
- logo.png
- jspdf.umd.min.js
- jspdf.plugin.autotable.min.js

Do not upload the ZIP file itself. Extract the ZIP first, then upload all six website files.

To publish with GitHub Pages:

1. Open your atlas-portal repository.
2. Upload the six website files and commit directly to the main branch.
3. Open Settings, then Pages.
4. Select "Deploy from a branch".
5. Choose "main" and "/ (root)", then Save.

The site will be available at:
https://mashhoodrizvi.github.io/atlas-portal/
