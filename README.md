ATLAS RETURNS & DIFFERENCES — GOOGLE SHEET VERSION

Upload these four files to the root of your GitHub repository:
- index.html
- style.css
- script.js
- logo.png

Your Google Sheet Row 1 must contain exactly these six headings:
Date | Actual Time | Invoice Time | Extra Time/Difference | Amount | Status

The website formats times automatically:
35:00:00 -> 35 hrs
13:20:00 -> 13 hrs 20 min
08:00:00 -> 8 hrs

To update the website, edit the Google Sheet and refresh the webpage.
