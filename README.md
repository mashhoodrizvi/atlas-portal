# Atlas Google Sheet Dashboard

Upload all four files in this folder to the root of your GitHub repository:

- index.html
- style.css
- script.js
- logo.png

Your Google Sheet is already connected.

## Google Sheet setup

Set sharing to:

**Anyone with the link — Viewer**

Row 1 must contain these exact headings:

1. Date
2. Actual Time
3. Invoice Time
4. Extra Time/Difference
5. Amount
6. Invoice Paid Date
7. Return Date
8. Status

To update the website, add a new row in Google Sheets, wait a few seconds, then refresh the website with Ctrl + F5.
